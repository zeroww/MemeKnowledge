# 梗世界 · 微信小游戏剧情答题 Demo

一款从宿舍到食堂到教室再到图书馆的校园梗知识生存答题游戏。

> 接不住梗，就出局。  
> 剧情关卡 · 10 题一局 · 3 条命 · BOSS 压轴 · 150 道内置演示题

## 故事背景

你穿越到了一个靠梗知识生存的世界：接住梗才能活下去，接不住梗的人会被世界淘汰。

你从陌生的大学宿舍醒来，室友嘉豪叫住了你，用 10 道梗知识题考验你能否活着走出这间宿舍。

宿舍 → 食堂 → 教室 → 图书馆，活过四章，才能找到回去的路。每一章都有新的对手、专属题池与剧情开场，通关后按顺序解锁下一章。

本工程参考微信小游戏示例的 Canvas 分层思路，用 Canvas 实现答题游戏。原示例代码与图片资源已移除；当前只包含新游戏实际使用的代码、数据与资源。短音效与背景音乐均由 WebAudio 程序化合成，不依赖外部音频文件。

## 快速开始

1. 用微信开发者工具导入本目录 `F:\wxProject\Memeknowledge`。
2. 项目类型为“小游戏”（`project.config.json` 中 `compileType: "game"`）。
3. 不需要 npm 安装、云开发环境或服务器；直接点击“编译”即可运行。
4. 使用鼠标/触摸点击即可完成全部操作。

> 如开发者工具提示 AppID 不属于当前账号，请把 `project.config.json` 中的 `appid` 替换为你自己的小游戏 AppID；本地编译可使用测试号，上传/发布前必须换成正式 AppID。

> 建议使用微信开发者工具的最新稳定版。真机体验需要预览/真机调试。

### 核心玩法

- 每局 10 题，第 1～3 题易、4～7 题中、8～9 题难、第 10 题 BOSS。
- 倒计时：12 / 12 / 12 / 10 / 10 / 10 / 10 / 9 / 9 / 8 秒。
- 3 条命；答错或超时扣 1 条；生命归零出局。
- 4 类题型：梗图猜梗、对话接话、真假梗、梗释义。
- 答对计分、答错展示正确答案与解释；屏幕震动/红闪/抖动。
- BOSS 题特殊横幅、音效与双倍得分（60 分）。

### 生存机制

- **复活**：每局最多 2 次；看广告或花 200 梗币；恢复 1 命并重答当前题，选项重新洗牌。
- **提示**：每局 2 次、每题 1 次；四选一移除 2 个错误项，真假题显示出处提示；可看广告或花 100 梗币。
- **加时**：剩余 ≤5 秒时出现；看广告 +5 秒；每局 1 次。
- **双倍**：通关结算页可看广告翻倍梗币一次；不影响排行榜分数。

### 内容与成长

- 150 道内置演示题库（易 60 / 中 55 / 难 35；BOSS 20；图片 30 / 接话 45 / 真假 35 / 释义 40）。
- 梗图鉴：答对解锁档案；支持全部/已解锁/未解锁筛选与详情。
- 梗币：分数 ×2 + 通关 100。
- 6 款主题皮肤：默认、锦鲤、黑色幽默、学霸、抽象面具、梗王；只改变视觉，无数值加成。
- 本地排行榜：周榜/总榜；玩家成绩 + 确定性演示机器人。
- 每日挑战功能已取消；首页与排行榜不再提供每日挑战入口。
- 设置：音效、背景音乐（对话轻松 / 答题紧张）、振动、昵称、隐私说明、关于、反馈说明、清除本地数据。
- 断点续玩：切后台暂停；本地快照 24 小时内可继续。
- 结算幂等：按 `runId` 记录发奖账本；重复进入结算页、重复领取、重复双倍都不会重复发奖。
- 分享成绩：标题 + 分数 query；分享不提供任何奖励。

### 背景音乐

- 程序化合成两套 BGM，不依赖外部音频文件：
  - **轻松**：首页、剧情开场、地图、结算、图鉴、排行榜、商店、设置。
  - **紧张**：普通答题页与剧情答题页（低音脉冲、心跳与高频提示）。
- 场景切换时自动淡出/淡入；设置页可单独关闭背景音乐。
- 受微信自动播放限制，首次用户交互后开始播放。

### 广告

- 默认 **Mock 广告**：完整观看后发奖；提前关闭不发奖，用于测试失败分支。
- 统一适配层：`js/services/ad-manager.js`。
- 已实现单局/每日广告上限、5 秒冷却、复活/提示/加时/双倍、插屏频控、金币兜底。
- 真实广告适配已完成，但需要流量主资格与广告位 ID 才能启用。

## 测试

```bash
npm test
```

包含：

- `tests/questions.test.mjs`：150 道题的数量、难度、题型、BOSS、答案、选项、字段校验。
- `tests/core.test.mjs`：抽题、满分 280、扣命/复活、提示/加时、双倍/幂等、倒计时、日期/周键。
- `tests/app-smoke.test.mjs`：模拟 `wx` + Canvas + 触摸，跑通首页 → 第一至第四章开场 → 章节专属 10 题 → 关卡结算 → 顺序解锁与校园地图 → 图鉴/榜单/商店/设置，以及提示、广告复活、加时、双倍、普通/剧情快照恢复、清除数据。

```bash

SCREEN_W=414 SCREEN_H=896 npm run test:smoke
```

## 启用真实广告

编辑 `js/services/config.js`：

```js
export const DEFAULT_CONFIG = {
  adsEnabled: true,
  mockAds: false,
  adUnits: {
    revive: '你的激励视频广告位 ID',
    hint: '你的激励视频广告位 ID',
    extend: '你的激励视频广告位 ID',
    double: '你的激励视频广告位 ID',
    interstitial: '你的插屏广告位 ID',
  },
  // ...
};
```

注意事项：

- 流量主未开通时保持 `adsEnabled: false` / `mockAds: true`。
- 真实广告必须在真机验证：无填充、提前关闭、播放中切后台、重复点击。
- 广告位 ID 是敏感配置，正式版建议由远程配置注入，不要散落在业务代码中。
- 单局激励视频上限 6 次、每日 12 次、冷却 5 秒；插屏首 3 局不弹。

## 题库维护

- 题库文件：`js/data/questions.js`。
- 每题包含：`id / packId / type / difficulty / stem / visual / options / answerKey / explanation / hint / source / heatPeriod / tags / isBoss / status`。
- 图片题不依赖外部图片，`visual.emojis` + `visual.caption` 由 Canvas 绘制原创抽象梗图。
- 选项在运行时按局洗牌，答案位置不需要人工随机化。
- 新增/修改题目后执行：

```bash
npm run test:questions
```

- 正式上线前必须人工复核事实、敏感词、版权与表达；当前 150 道为开发阶段演示内容。
- 下架题目：把 `status` 改为 `retired`；新局不再抽取。

## 本地数据

使用 `wx.setStorageSync`，键名以 `mw_v1_` 开头：

- `mw_v1_profile`：昵称、梗币、图鉴、皮肤、设置、广告次数、排行榜最佳成绩、最近题目、结算账本 `claimedRuns`。
- `mw_v1_run_snapshot`：进行中的对局快照（24 小时有效）。
- `mw_v1_events`：最近 300 条本地埋点事件。
- `mw_v1_meta`：安装信息。

设置页“清除我的数据”会删除全部 `mw_v1_*` 键并重置为初始资料。

## 已知限制（本轮 Demo）

- 剧情模式已开放第一至第四章（宿舍 / 食堂 / 教室 / 图书馆）；第四章「图书馆」为最终章，通关后结算页会提示找到回去的路。
- 角色使用去底透明 PNG；背景与地图使用压缩 JPG；原始高清 PNG 在 `.claude/profile/`，不参与打包。
- 当前打包估算约 3.7MB（代码约 430KB + 剧情与首页图片约 3.3MB；`docs/tests/tools/.claude`、旧图标目录 `assets/ui/icons` 与合成源图 `assets/ui/generated-image.png` 已排除）。第四章角色 PNG 已量化为 220 色以控制包体。
- 没有 CloudBase / 服务端权威判题；排行榜为本地演示榜单，不是真实全服排名。
- 广告默认是模拟广告；真实广告需要流量主与广告位 ID。
- 没有 Banner 广告；插屏为 Mock。
- 没有题包商店、打字答题、5 连 BOSS、实时 PK、内购。
- 分享为标题 + query，没有自定义分享卡片图片。
- 昵称修改依赖 `wx.showModal` 的 `editable` 能力；未接微信内容安全接口。
- 背景音乐为 WebAudio 程序化合成：对话/首页/地图/结算等使用轻松慢节奏铺底，答题页切换为紧张低音脉冲；默认开启，可在设置关闭。
- 广告次数以设备本地时间为准，存在可修改的体验级限制。
- 150 道题库为演示内容，上线前必须内容复核与版权确认。
