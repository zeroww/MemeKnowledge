校验内容：

- 选项数量：四选一 4 项，真假题 2 项。
- `answerKey` 必须存在于选项中。
- 选项文本不重复、字段非空。
- BOSS 题必须为难度 3。
- 图片题必须有 `visual.emojis`。
- 题干/选项/解释长度阈值检查（无警告）。

```bash
node tests/core.test.mjs
```

结果：**PASS**
